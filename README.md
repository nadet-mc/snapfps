# SnapFPS - FPS Display Mod

![FPS Display Banner](https://nadetmc.site/assets/banner.png)

SnapFPS is a lightweight, customizable FPS display mod for Minecraft (Fabric), designed to help you monitor your game's performance in real time.  
Easily tweak the look and feel of the FPS counter to match your preferences!

---

## ✨ Features

- 📊 **Real-Time FPS Counter**: Always know your current frames per second.
- 🎨 **Customizable Appearance**: Change text size, color, alpha, shadow, and position.
- 🔑 **Toggle & Keybind Modes**: Enable/disable the display or switch modes with a keybind.
- ⚙️ **Advanced Stats**: Optionally show more detailed performance info.
- 🧩 **Fabric API Support**: Seamless integration with the Fabric mod loader.
- 🛠️ **Configurable In-Game**: Use the YACL-powered config screen for easy setup.

---

## 🚀 Installation

1. **Download** the latest SnapFPS release from [GitHub Releases](https://github.com/nadetmc/snapfps/releases) or [nadetmc.site](https://nadetmc.site).
2. **Install** [Fabric Loader](https://fabricmc.net/use/) for your Minecraft version (1.21.1–1.21.4 recommended).
3. **Add** SnapFPS and [Fabric API](https://modrinth.com/mod/fabric-api) to your `mods` folder.
4. **(Optional)**: For in-game config, install [Cloth Config](https://modrinth.com/mod/cloth-config) or [YACL](https://modrinth.com/mod/yet-another-config-lib).
